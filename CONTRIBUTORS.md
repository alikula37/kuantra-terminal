# Contributors

Kuantra Terminal uses human-owned, AI-assisted development. Product authority and release
approval remain with the repository owner; AI contributions are recorded explicitly.

## Current contributors

The named AI roles below record the original workflow, not permanent model requirements.
Current user instructions take precedence; if a subagent is requested for the Mac
continuation, use GPT-5.6 Luna. An agent may review and integrate work but cannot
approve product-market changes, financial authority, main merges or releases for the owner.

- **alikula37** — Product owner and repository maintainer.
- **Axiom — GPT-5.6 SOL** — Product strategy, FinTech systems architecture, security review,
  work-package ownership, integration and final code review.
- **GPT-5.6 Terra** — Scoped implementation agent operating under Axiom's work packages and
  acceptance criteria.

AI-authored changes are not accepted on generation alone. They require repository tests,
documented acceptance criteria and lead-agent review before commit.
