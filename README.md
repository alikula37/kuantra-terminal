## 🚀 Quickstart & Local Development

### 1. Prerequisites
- **Node.js**: `v18.0.0+` or `v20.0.0+`
- **Python**: `3.11.0+` with `pip`
- **Rust / Cargo**: `1.75.0+` (for Tauri desktop runtime)
- **C++ Compiler**: MSVC (Windows), Clang (macOS), GCC (Linux)

### 2. Clone Repository
```bash
git clone https://github.com/alikula37/kuantra-terminal.git
cd kuantra-terminal
```

### 3. Backend Setup & Test Execution
```bash
# Install Python dependencies
pip install -r backend/requirements.txt

# Execute full pytest verification suite across all 18 phases (108+ tests)
pytest backend/tests -v --tb=short
```

### 4. Frontend Compilation & Desktop Run
```bash
# Install frontend dependencies
cd frontend
npm install

# Compile production bundle (TypeScript strict validation)
npm run build

# Launch Tauri Desktop Application in Development Mode
cd ..
npm run tauri dev
```

## 🔒 Security & Cryptographic Integrity

- **Zero Plaintext Credentials**: All broker API keys (TwelveData, Polygon, Binance, OKX, FIX) are derived via PBKDF2/Argon2id (100,000 iterations) and encrypted in memory using **AES-256-GCM**.
- **PII / Secret Scrubbing**: All rotating logs automatically strip API keys (`sk_live_...`), authorization headers, and account equity figures before disk flushing.
- **Hardware Passkey Gating**: Institutional orders $> \$50,000$ mandate biometric WebAuthn / FIDO2 hardware enclave assertion before dispatch.
